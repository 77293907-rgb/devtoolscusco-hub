# devToolsCusco — Hub Principal

Hub tecnológico y aceleradora de talento del Cusco. Digitalizamos PyMEs turísticas
con **software a medida** e **infraestructura inteligente (domótica)**.

## 🎯 Propósito

Prototipo funcional que actúa como **presentación corporativa** y **vitrina interactiva**
para conectar clientes (hoteles boutique, lodges, restaurantes) con los prototipos de:

- 🗓️ Sistema de Reservas → `productos/reservas.html`
- 🏠 Panel Domótico → `productos/domotica.html`

## 🛠️ Stack

- **HTML5 semántico**
- **TailwindCSS vía CDN** (con `tailwind.config` inline para paleta de marca)
- **CSS3 personalizado** (`assets/css/styles.css`)
- **Vanilla JavaScript** (`assets/js/main.js`)
- **Fuentes:** Sora (títulos) + Inter (cuerpo)
- **Cero dependencias de build** — prototipo 100% portátil
